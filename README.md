## 📖 About ZORIQ

**ZORIQ** is an ultra-fast, privacy-first platform providing high-performance utility tools for developers, designers, students, and everyday internet users.

Unlike conventional web tools that upload sensitive documents and data to third-party cloud servers, **ZORIQ processes everything 100% client-side** using native browser APIs (HTML5 Canvas, Web Workers, Web Crypto, FileReader, and WebAssembly). Your files, images, passwords, and tokens **never leave your machine**.

## ✨ Platform Highlights

- **🔒 Zero-Knowledge Privacy**: 100% of computational heavy lifting occurs client-side. No user files or tokens are ever sent to a database or server.
- **⚡ Global Command Palette**: Press `Cmd + K` or `Ctrl + K` anywhere on the site for instantaneous keyboard navigation to any tool.
- **📋 Clipboard Paste Listeners**: Press `Ctrl + V` / `⌘ + V` on file dropzones to import screenshots directly from your clipboard.
- **📱 Responsive Design & Dark Mode**: Seamless dark/light theme switching with zero layout shift (CLS).
- **🎯 SEO & Structured Data**: Automated Next.js App Router metadata, Schema.org `WebApplication` JSON-LD schemas, and dynamic sitemaps.
- **✉️ Direct Feedback Integration**: Automated transactional email delivery via Resend API.

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18.17 or higher
- **npm** or **pnpm** or **yarn**

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Puttaraj/zoriq.git
   cd zoriq
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the project root:

   ```env
   NEXT_PUBLIC_SITE_URL=http://localhost:3000
   NEXT_PUBLIC_SITE_NAME=ZORIQ

   # Optional: Resend API for contact form email delivery
   RESEND_API_KEY=your_resend_api_key_here
   CONTACT_RECIPIENT_EMAIL=hello@zoriq.co.in
   ```

4. **Run the development server:**

   ```bash
   npm run dev
   ```

5. **Open the application:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
